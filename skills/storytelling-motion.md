# Storytelling Motion Skill

## Philosophy
The landing page should feel immersive and cinematic.

Scrolling should feel like moving through a designed spatial experience rather than browsing static sections.

## Use
- sticky storytelling sections
- pinned content transitions
- layered parallax
- image masking reveals
- cinematic fades
- overlapping compositions
- animated product reveals
- motion-driven narrative pacing

## Layout
Sections may overlap and transition into each other naturally.

Use asymmetrical compositions and depth layering.

## Motion Systems
- Framer Motion
- GSAP ScrollTrigger for advanced storytelling
- Lenis smooth scrolling if needed

## Preferred Effects
- image zoom reveals
- floating glass cards
- progressive dashboard reveals
- staggered content choreography
- animated grids
- scroll-based opacity transitions
- layered typography motion

## Avoid
- static section stacking
- generic SaaS blocks
- repetitive layouts
- excessive bouncing
- chaotic animations

## Goal
Create a memorable premium web experience that feels:
- architectural
- emotional
- immersive
- spatial
- cinematic

## Environmental Continuity

The website should behave as one cinematic world.

Avoid:
- abrupt background changes
- disconnected motion systems
- isolated transitions

Use:
- persistent atmospheric layers
- connected scroll choreography
- evolving lighting environments
- continuous visual depth
- shared spatial movement between sections
