# Dashboard Direction

## Philosophy
Dormly dashboards should feel operational yet premium.

The UI should resemble:
- luxury building operations
- architectural control systems
- modern hospitality management

NOT:
- enterprise ERP
- crypto admin panels
- generic analytics tools

---

# Dashboard Tone

Interfaces should feel:
- calm
- structured
- breathable
- high-end
- intelligent

Avoid:
- overcrowded widgets
- excessive charts
- too many colors
- sharp contrast overload

---

# Layout Direction

Use:
- layered panels
- floating metric cards
- asymmetric grids
- editorial spacing
- spacious content rhythm

Avoid:
- equal card layouts
- tiny dense widgets
- dashboard clutter

---

# Metrics

Metrics should:
- feel important
- use large restrained typography
- avoid flashy growth indicators

Preferred:
- occupancy
- maintenance pressure
- complaint resolution
- operational health

Avoid:
- startup KPI overload
- rainbow analytics

---

# AI Panels

AI interactions should feel:
- calm
- conversational
- intelligent
- embedded naturally

Avoid:
- chatbot gimmicks
- glowing AI effects
- neon interfaces
