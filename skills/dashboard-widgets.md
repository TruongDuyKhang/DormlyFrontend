# Dashboard Widgets

## Metric Cards
Use:
- large mono numbers
- muted labels
- soft glass backgrounds
- subtle borders

Avoid:
- colorful KPI spam
- aggressive icons

---

# Tables
Tables should feel:
- lightweight
- breathable
- modern

Use:
- large row height
- soft separators
- minimal borders

Avoid:
- enterprise table density

---

# Charts
Preferred charts:
- occupancy trends
- maintenance load
- complaint flow
- ticket deadlines

Style:
- monochrome
- soft neutral tones
- minimal axes
- architectural rhythm

Avoid:
- rainbow charts
- finance-style graphs

---

# Notifications
Notifications should:
- feel editorial
- use subtle contrast
- maintain calm hierarchy

Avoid:
- loud warning systems
- excessive red colors
